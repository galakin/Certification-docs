\begin{itemize}
	\item \textbf{On-demand services}: without the need of human interaction

	\item \textbf{Measured service}	user pay for what they use

\section{EC2}

EC2 User Data script run with \textbf{root user}.\\
EC2 instance are billed on a \textbf{per minute (60 sec)} base.\\

AWS has the following naming convention:\\
\textbf{m5.2xlarge}\\
• m: instance class\\
• 5: generation (AWS improves them over time)\\
• 2xlarge: size within the instance class\\

Usage beyond Savings Plans is billed at the On-Demand price.\\

\subsection{Security Groups}
Security Groups control how traffic is allowed into or out of our instances.\\
Security groups only contain \textbf{allow} rules.\\
Security groups rules can reference by IP or by security group.\\
They controll both inbout and outbound traffic
Security Group are linked to the specific \textbf{region and VPC} where they are created.\\
Security group roles are stateful, meaning they allow automatically the return traffic.

If your application is not accessible (time out), then it’s a security group issue.\\

\subsection{EBS Volume}
They can only be mounted to one instance at a time.\\
They are bound to a specific availability zone.\\
It’s locked to an Availability Zone, to move a volume you need to take a snapshot.\\
EBS volume can be attached to a single instance in the same Availability Zone (AZ).
whereas EFS file system can be mounted on instances across multiple Availability Zones (AZ)

\subsection{EBS Snapshots}
Make a backup (snapshot) of your EBS volume at a point in time.\\
You can move your EBS snapshot to a cheaper archive tier.\\
You can specify a retention policy (1 day - 1 year) for your deleted EBS snapshot\\
EBS Snapshot archive are 75\% cheaper\\

\section{AWS Global Accelerator}
AWS Global Accelerator is a service that improves the availability and performance of your applications with local or global 
users. It provides static IP addresses that act as a fixed entry point to your application endpoints in a single or multiple 
AWS Regions, such as your Application Load Balancers, Network Load Balancers, or Amazon EC2 instances. AWS Global Accelerator 
uses the AWS global network to optimize the path from your users to your applications, improving the performance of your 
traffic by as much as 60\%.

\section{Well-architected framework}
The AWS Well-Architected Framework provides guidance on building secure, high-performing, resilient, and efficient infrastructure 
for cloud based applications. Based on six pillars:
\begin{itemize}
	\item operational excellence
	\item security
	\item reliability
	\item performance efficiency
	\item cost optimization
	\item sustainability
\end{itemize}

\subsection{AWS CAF}
AWS CAF groups its capabilities in six perspectives:\textbf{Business, People, Governance, Platform, Security, and
Operations}\\

\textbf{The Business Perspective} of the AWS CAF ensures that cloud adoption strategies align with the 
organization's business objectives. It focuses on strategic planning, value realization, and benefits tracking to ensure 
cloud adoption drives business success.\\

\textbf{The Governance Perspective} focuses on managing risks, compliance, and financial management in the 
cloud. While important, it does not directly address aligning IT strategy with business objectives.\\

\textbf{The Operations Perspective} emphasizes day-to-day workload operations, monitoring, and performance 
management. It does not focus on strategy alignment with business goals.\\

\textbf{The Platform Perspective} is centered on designing, implementing, and optimizing cloud services and 
applications. Helps you build an enterprise-grade, scalable, hybrid cloud platform; modernize existing workloads; 
and implement new cloud-native solutions.\\

\textbf{Security Perspective} helps you achieve the confidentiality, integrity, and availability of your data and 
cloud workloads.\\

\textbf{Operations Perspective} helps ensure that your cloud services are delivered at a level that meets the needs 
of your busines

\section{Amazon GuardDuty}

in your accounts), Amazon VPC Flow Logs (network traffic data), and DNS Logs (name query patterns).\\
