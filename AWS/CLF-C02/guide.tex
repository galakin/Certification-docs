The certification cover over \textbf{40 AWS services}\\
Creation resources in the cloud cost money.\\

Creating and AWS account require an email for the root user and and AWS account name.

Cloud computing is the on-demand delivery of compute power, database storage,
applications, and other IT resources.\\
Through a cloud services platform with pay-as-you-go pricing\\
You can provision exactly the right type and size of computing resources you need\\

AWS is one of the many cloud provider available on the market!\\

The five caratteristics of cloud compunting are the following:
\begin{itemize}
	\item \textbf{On-demand services}: without the need of human interaction 
	\item \textbf{Broad network access}: resources can be accessed everywhere
	\item \textbf{Multi-tenancy and resource pooling} multiple customer ar served on the same resources
	\item \textbf{Rapid elasticity and scalability} easily create and dispose of resources 
	\item \textbf{Measured service}	user pay for what they use 
\end{itemize}

AWS has 3 pricing fundamentals:
\begin{itemize}
	\item \textbf{Compute}: Pay for your computational time 
	\item \textbf{Storage}: Pay for data stored 
	\item \textbf{Data transfered OUT of the cloud} 
\end{itemize}

Shared resposability Model\\
You are responsible for the security \textbf{IN} the cloud\\
AWS is resposible for the security \textbf{OF} the cloud\\

\section{IAM}
AWS IAM is one of the few \textbf{global} services\\

On AWS you apply the \textbf{least privilege} principle for the user and services IAM policy

\subsection{IAM Security Tools}
\textbf{IAM Credentials Report} (account-level) is a service used to lists of all your account's users and the status of their various
credentials.\\
\textbf{IAM Access Advisor} (user-level) is a service used to shows the service permissions granted to a user and when those
services were last accessed. You can use this information to revise your policies.\\

\textbf{Don’t use the root account except for AWS account setup}\\

EC2 User Data script run with \textbf{root user}

\section{EC2}
AWS has the following naming convention:\\
\textbf{m5.2xlarge}\\
• m: instance class\\
• 5: generation (AWS improves them over time)\\
• 2xlarge: size within the instance class\\

\subsection{Security Groups}
Security Groups control how traffic is allowed into or out of our instances.\\
Security groups only contain \textbf{allow} rules.\\
Security groups rules can reference by IP or by security group.\\
They controll both inbout and outbound traffic
Security Group are linked to the specific \textbf{region and VPC} where they are created

If your application is not accessible (time out), then it’s a security group issue.\\
Usage beyond Savings Plans is billed at the On-Demand price.\\

\subsection{EBS Volume}
They can only be mounted to one instance at a time.\\
They are bound to a specific availability zone.\\
It’s locked to an Availability Zone, to move a volume you need to take a snapshot.\\

\subsection{EBS Snapshots}
Make a backup (snapshot) of your EBS volume at a point in time.\\
You can move your EBS snapshot to a cheaper archive tier.\\
You can specify a retention policy (1 day - 1 year) for your deleted EBS snapshot\\
